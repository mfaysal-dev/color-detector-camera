
## Color Detector — mfaysal.com

A real-time color detection tool that identifies the color at the center of your camera view. Shows color name in Bengali, HEX code, and RGB values instantly.

---

## ✨ Features
- ✅ Live camera feed with center crosshair
- ✅ Instant color name detection in Bengali
- ✅ HEX & RGB color codes displayed
- ✅ Smooth color preview display
- ✅ Clean professional design
- ✅ Works on mobile & desktop
- ✅ Pure JavaScript — no libraries needed

## 🚀 How to Use
1. Save all files in one folder
2. Open `index.html` in browser
3. Click **"Open camera"**
4. Allow camera permission
5. Point camera at any color — result updates instantly

---

## 📋 Requirements
- Modern browser (Chrome, Firefox, Edge, Safari)
- Camera permission enabled
- HTTPS or localhost for online use

---

## 🎨 Customization
- Change colors in `style.css` → `:root` section
- Add more color names in `script.js` → `getColorName()` function
- Adjust crosshair size in `style.css` → `.crosshair`
